🚀 Como executar o projeto
Clone este repositório:
git clone: https://github.com/JeanMNP/CV_Online.git

Acesse a pasta do projeto:
cd seu-repositorio

Instale as dependências:
npm install

Execute o projeto:
npm run dev

O site estará disponível em http://localhost:5173/
